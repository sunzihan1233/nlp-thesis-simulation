# 基于多种文本相似度测度的中文短文本情感分类研究
模拟毕业论文项目
本项目为NLP课程模拟毕业论文，实现Jaccard、编辑距离、TF‑IDF余弦、Sentence‑BERT四类相似度NLP测度构建，完成中文短文本情感二分类实验。

## 环境依赖
pip install jieba scikit-learn sentence-transformers numpy

## 文件说明
- thesis.md：模拟毕业论文全文
- experiment.py：完整实验代码

## 运行
python experiment.py
